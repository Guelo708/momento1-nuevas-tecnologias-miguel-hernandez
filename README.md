#  Sistema de Inventarios en Python

Este proyecto implementa un sistema de inventarios modularizado en Python, pensado para prácticas académicas y sustentaciones.  
Permite registrar productos, consultar inventario, retirar unidades y generar reportes de salidas y valores monetarios.

---

##  Funcionalidades

1. **Registrar producto**  
   - Guarda nombre, precio y cantidad en el inventario.

2. **Mostrar inventario detallado**  
   - Muestra productos con precio unitario, cantidad, valor total por referencia y el total general del inventario.

3. **Sacar producto**  
   - Retira unidades de un producto.  
   - Calcula el valor monetario de la salida y lo registra.

4. **Ver registros de salida**  
   - Lista todas las salidas realizadas con detalle de producto, cantidad y valor.

5. **Salir**  
   - Finaliza el programa.
